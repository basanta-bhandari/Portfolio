WHAT V1 ACTUALLY DOES

Current capabilities

Every device has its own identity. Pairing is manual: enter a reachable address and public key, then approve the request on the other device. This is still a v1 developer preview, not a finished consumer messenger.

  1. MessagesOne-to-one messages between trusted devices, with conversation history stored locally.
  2. MailA local inbox and durable outgoing queue that retries while Tether is running.
  3. FilesOne-time file copies between trusted devices. Core storage remains experimental.
